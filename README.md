# 洪工杯报名 H5

2026年南昌市“洪工杯”网络舆情应对处置职工职业技能竞赛 · 报名填表页（Angular）。

## 在线访问

- 洪工杯报名：https://john-sh.github.io/MiduGuanWang/hgcompetition/
- 申请试用页：https://john-sh.github.io/MiduGuanWang/apply/
- 订单与发票中心：https://john-sh.github.io/MiduGuanWang/orders/

## 本地运行

```bash
export PATH="$HOME/.local/node/bin:$PATH"
npm start
```

浏览器打开 `http://localhost:4200/`。

## 功能说明

- 参赛单位、战队名称、3 位联系人、手机号、验证码
- 社保证明 3 份 + 工会法人资格证书上传（≤5MB，PDF/PNG/JPG/JPEG）
- 用户协议勾选与表单校验
- 验证码发送与提交当前为前端模拟，可后续对接接口
