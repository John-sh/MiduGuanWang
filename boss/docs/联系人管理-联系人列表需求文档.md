## 1. 背景与目标

运营在 BOSS 中查看官网 / 小程序 / App 注册的联系人主档，点进详情查看该联系人的行为轨迹与意向温度（冷 / 温 / 热）。

同一套联系人列表同时服务两条运营线：**GEO 小程序（9.9 元评估）** 与 **模力通 App（15 天 3000 点体验 / 99 元年包）**。行为分累计模力通 APP 与 GEO 用户行为。模力通 APP 行为记录暂定为注册、登录、功能使用-写作、功能使用-会议纪要。运营套餐按来源匹配。列表不提供发短信。


| 模块    | 菜单位置  | 展示内容                | 操作         |
| ----- | ----- | ------------------- | ---------- |
| 联系人列表 | 联系人管理（线索管理下方） | 主表字段                | 详情、打标签、转表单 |
| 详情弹窗  | 列表点详情 | 全屏：主表字段 + 行为汇总 / 轨迹 | 关闭         |


联系人 ≠ 客户。侧栏顺序：线索管理 → **联系人管理** → 客户管理。

## 3. 详情内容

点「详情」打开**全屏覆盖**弹窗（盖住整页，含侧栏）。

标题：`联系人详情 【{联系人姓名 / 昵称 / 手机号}】` + 行为等级。身份状态、数据状态只在基本信息中展示。

上半部分 **基本信息**：四列表格式，字段顺序与列表一致，并补一级 / 三级渠道、体验天数 / App操作次数。不含联系人ID、来源渠道、联系人来源、创建人、剩余点数、已用点数。来源标签展示最新一条行为的来源标签。

下半部分 **行为**：左侧行为汇总，右侧**行为记录流水**（只记用户行为），规则表在下方通栏。行为记录可按**产品**筛选（暂定：模力通、蜜度GEO）。合计得分、等级累计模力通 APP 与 GEO 用户行为。不展示短信监测。

以表格展示，列：序号、字段、内容。口径跨全部产品。


| 字段名             | 中文名    | 必填  | 说明                   |

| first_login_at  | 首次登录时间 | 否   | datetime，取全部产品最早一次登录 |
| login_count     | 登录次数   | 否   | 默认 0，全部产品登录次数之和      |

### 3.2 行为记录

`behavior_track`（json）。详情右侧以**流水**展示用户行为，列：时间、行为。只记录用户行为，不记运营发短信等后台动作。每条记录带产品：`模力通` / `蜜度GEO`。

表头提供筛选项：

- **产品**：暂定 `模力通`、`蜜度GEO`，可清空。未选时展示全部产品记录。
- **时间**：日期范围，从日历**点选**（不可手工输入），**按天**查询（闭区间，只比较 `yyyy-MM-dd`，忽略时分秒）。未选日期时展示全部记录。

筛选只影响流水，不影响行为汇总、行为分和行为等级。行为分累计模力通 APP 与 GEO 用户行为。

无数据：未筛选「暂无行为记录」；已选产品「该产品暂无行为记录」；已选时间「该时间范围内暂无行为记录」；产品+时间「该筛选条件下暂无行为记录」。

流水下方为**行为等级规则表**，列：等级、分数区间、规则、匹配。命中的等级标「当前」并高亮。

旁注小字（暂定）：可按产品筛选。模力通 APP 行为含注册、登录、功能使用-写作、功能使用-会议纪要。蜜度GEO 恢复原用户行为记录。**具体以产品传输内容为准。**

### 3.5 列表操作

- **详情**：打开全屏详情。
- **打标签**：多选标签（已注册未下单 / 体验中 / 已充值 / 已下单未开票 / 已绑定主体 / 已开票 / S / A / B / C）后保存，覆盖写入「标签」并更新最新操作人。不修改来源标签、不修改身份状态。可清空。
- **转表单**：未转时弹出表单。必填：**单位、联系人姓名、手机号、产品**。选填：邮箱、来源、跟进人、需求描述。确认后生成 2 开头 6 位表单 ID，写回单位 / 姓名 / 手机号等，并在列表「表单ID」列回显。已转则按钮禁用。
- 列表无「发短信」、无「批量发短信」。不在详情展示短信监测。

| 字段    | 必填  | 来源        | 原因                      |

| 单位    | 是   | 预填客户主体名称  | 线索必须落到一家单位              |
| 联系人姓名 | 是   | 预填姓名      | 销售跟进时的称呼                |
| 手机号   | 是   | 预填手机号     | 线索触达主号码                 |
| 产品    | 是   | 预填首个意向产品线 | 明确这条线索跟哪条产品             |
| 邮箱    | 否   | 预填邮箱      | 发送发票                    |
| 来源    | 否   | 预填来源      | 线索归因，字典同 2.5            |
| 跟进人   | 否   | 默认当前用户    | 转出后谁接手                  |

## 4. 行为等级打分逻辑

行为分挂在**联系人**上。累计模力通 APP 与 GEO 用户行为，定冷温热。

### 4.1 计算公式

```
行为分 = Σ 该联系人全部用户行为记录的得分（模力通 APP + GEO）
行为等级 = 映射(行为分)
```

- 列表「行为分 / 行为等级」与详情合计使用同一套结果。
- 模力通 APP 与 GEO 记录一并加分，不按产品拆分合计。
- 同一行为在不同时间发生多次：按轨迹**逐条累计**（例如多次登录）。
- 轨迹没有的行为不计分。



### 4.2 分值表


| 行为         | 分值  | 计分方式    | 产品    |
| ---------- | --- | ------- | ----- |
| 注册         | +10 | 按记录条数   | 共用    |
| 登录         | +2  | 每次登录 +2 | 共用    |
| 功能使用-写作    | +8  | 按记录条数   | 模力通 APP |
| 功能使用-会议纪要  | +8  | 按记录条数   | 模力通 APP |
| 点击 9.9 元体验 | +10 | 按记录条数   | 蜜度GEO |
| 进入订单页      | +15 | 按记录条数   | 蜜度GEO |
| 绑定主体       | +20 | 按记录条数   | 蜜度GEO |
| 提交开票       | +10 | 按记录条数   | 蜜度GEO |


未在表中的行为不得分。模力通 APP 行为暂定上表四项。

### 4.3 等级映射


| 行为分 S       | 等级     |
| ----------- | ------ |
| S ≥ 46      | 热      |
| 21 ≤ S ≤ 45 | 温      |
| 10 ≤ S ≤ 20 | 冷      |
| S ≤ 9       | -（不评级） |


边界：20 分仍为冷，21 分为温，45 分为温，46 分为热。

### 4.4 订单汇总（与打分独立）

打分只看轨迹。行为汇总里的订单字段另算：

- **订单数** = 该联系人全部产品订单条数（含未支付）。
- **订单金额** = 其中 `已支付` 订单金额之和。未支付、已取消不计金额。
- **是否下单** = 订单数 > 0。

样例：张伟有 GEO 已支付 9.9 元、舆情平台未支付 8,600 元 → 订单数 2，订单金额 9.90。
