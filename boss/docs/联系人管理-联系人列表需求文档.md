## 1. 背景与目标

运营在 BOSS 中查看官网 / 小程序 / App 注册的联系人主档，点进详情查看该联系人的行为轨迹与意向温度（冷 / 温 / 热）。

当前样例产线：**蜜度GEO小程序评估套餐**、**舆情平台**。行为轨迹与汇总展示全部产品上的行为；行为分是全部轨迹得分之和。


| 模块    | 菜单位置  | 展示内容                | 操作         |
| ----- | ----- | ------------------- | ---------- |
| 联系人列表 | 联系人管理 | 主表字段                | 详情、打标签、转表单 |
| 详情弹窗  | 列表点详情 | 全屏：主表字段 + 行为汇总 / 轨迹 | 关闭         |


联系人 ≠ 客户。客户管理菜单保留。

## 3. 详情内容

点「详情」打开**全屏覆盖**弹窗（盖住整页，含侧栏）。

标题：`联系人详情 【{联系人姓名 / 昵称 / 手机号}】` + 行为等级。身份状态、数据状态只在基本信息中展示。

上半部分 **基本信息**：四列表格式，字段顺序与列表一致，并补一级 / 三级渠道。不含联系人ID、客户主体ID、备注、来源渠道、联系人来源、创建人。

下半部分 **行为**：行为汇总与行为轨迹左右分栏，规则表在下方通栏。**无产品切换**。汇总、轨迹、合计得分、等级均为该联系人全部行为。

### 3.1 行为汇总

以表格展示，列：序号、字段、内容。口径跨全部产品。


| 字段名             | 中文名    | 必填  | 说明                   |
| --------------- | ------ | --- | -------------------- |
| first_login_at  | 首次登录时间 | 否   | datetime，取全部产品最早一次登录 |
| login_count     | 登录次数   | 否   | 默认 0，全部产品登录次数之和      |
| last_active_at  | 最近活跃时间 | 否   | datetime，全部产品最近一次    |
| last_behavior   | 最近关键行为 | 否   | 枚举见 3.3，取时间最近的一条关键行为 |
| key_event_count | 关键事件次数 | 是   | 默认 0，全部产品关键行为条数之和    |
| has_order       | 是否下单   | 否   | 任一产品有订单即为「是」         |
| order_count     | 订单数    | 否   | **统计全部产品的订单数**，含未支付  |
| order_amount    | 订单金额   | 否   | **只含已支付订单金额**之和      |


已删除：开票状态。

### 3.2 行为轨迹

`behavior_track`（json）。详情表格列：序号、时间、行为、得分。

表头提供筛选项 **时间**：日期范围，从日历**点选**（不可手工输入），**按天**查询（闭区间，只比较 `yyyy-MM-dd`，忽略时分秒）。未选日期时展示全部轨迹。筛选只影响轨迹表，不影响行为汇总、行为分和行为等级。

表底「合计得分」= 当前筛出轨迹行得分之和。无数据：未筛选时「暂无行为轨迹」；已选时间时「该时间范围内暂无行为轨迹」。

轨迹表下方为**行为等级规则表**，列：等级、分数区间、规则、匹配。命中的等级标「当前」并高亮。

表底说明：行为分按联系人全部轨迹合计，不按产品拆分。底部：关闭。

### 3.3 行为轨迹枚举

写入轨迹的标准行为（按漏斗从浅到深）：


| 行为                  | 是否关键行为 | 说明              |
| ------------------- | ------ | --------------- |
| 完成注册 + 授权手机号 + 同意协议 | 否      | 首次身份建立          |
| 登录                  | 否      | 每次登录记一条         |
| 浏览产品页               | 否      | 访问产品介绍 / 套餐页    |
| 点击 9.9 元体验          | 是      | 点击体验购入口         |
| 填写表单                | 是      | 提交试用 / 资料 / 咨询表 |
| 预约演示                | 是      | 预约人工或产品演示       |
| 进入订单页               | 是      | 打开下单 / 结算页      |
| 下单                  | 是      | 生成订单，不论是否支付     |
| 支付成功                | 是      | 订单已支付           |
| 绑定主体                | 是      | 绑定客户主体          |
| 提交开票                | 是      | 提交开票申请          |




### 3.4 关键行为枚举

用于「最近关键行为」「关键事件次数」：

点击 9.9 元体验、填写表单、预约演示、进入订单页、下单、支付成功、绑定主体、提交开票。

登录、注册、浏览产品页不计入关键事件。

### 3.5 列表操作

- **详情**：打开全屏详情。
- **打标签**：单选 S / A / B / C 后保存，更新「标签」与最新操作人。不修改来源标签。
- **转表单**：未转时弹出表单。必填：**单位、联系人姓名、手机号、产品**。选填：邮箱、来源、跟进人、需求描述。确认后生成 2 开头 6 位表单 ID，写回单位 / 姓名 / 手机号等，并在列表「表单ID」列回显。已转则按钮禁用。

转表单字段说明：


| 字段    | 必填  | 来源        | 原因                      |
| ----- | --- | --------- | ----------------------- |
| 单位    | 是   | 预填客户主体名称  | 线索必须落到一家单位              |
| 联系人姓名 | 是   | 预填姓名      | 销售跟进时的称呼                |
| 手机号   | 是   | 预填手机号     | 线索触达主号码                 |
| 产品    | 是   | 预填首个意向产品线 | 明确这条线索跟哪条产品             |
| 邮箱    | 否   | 预填邮箱      | 发送发票                    |
| 来源    | 否   | 预填来源      | 线索归因，字典同 2.5            |
| 跟进人   | 否   | 默认当前用户    | 转出后谁接手                  |

## 4. 行为等级打分逻辑

行为分挂在**联系人**上，不按产品线分桶。所有产品上发生的行为记在同一条轨迹里，一起加分、一起定冷温热。

### 4.1 计算公式

```
行为分 = Σ 该联系人全部行为轨迹条目的得分
行为等级 = 映射(行为分)
```

- 列表「行为分 / 行为等级」与详情合计使用同一套结果。
- 不按产品过滤，不按产品取最高分。
- 同一行为在不同时间发生多次：按轨迹**逐条累计**（例如多次登录、跨产品多次点击体验）。
- 轨迹没有的行为不计分。



### 4.2 分值表


| 行为         | 分值  | 计分方式    |
| ---------- | --- | ------- |
| 完成注册       | +10 | 按轨迹条数   |
| 登录         | +2  | 每次登录 +2 |
| 浏览产品页      | +3  | 按轨迹条数   |
| 点击 9.9 元体验 | +10 | 按轨迹条数   |
| 填写表单       | +8  | 按轨迹条数   |
| 预约演示       | +12 | 按轨迹条数   |
| 进入订单页      | +15 | 按轨迹条数   |
| 下单         | +15 | 按轨迹条数   |
| 支付成功       | +20 | 按轨迹条数   |
| 绑定主体       | +20 | 按轨迹条数   |
| 提交开票       | +10 | 按轨迹条数   |


未在表中的行为不得分。

### 4.3 等级映射


| 行为分 S       | 等级     |
| ----------- | ------ |
| S ≥ 46      | 热      |
| 21 ≤ S ≤ 45 | 温      |
| 10 ≤ S ≤ 20 | 冷      |
| S ≤ 9       | -（不评级） |


边界：20 分仍为冷，21 分为温，45 分为温，46 分为热。

### 4.4 订单汇总（与打分独立）

打分只看轨迹。行为汇总里的订单字段另算：

- **订单数** = 该联系人全部产品订单条数（含未支付）。
- **订单金额** = 其中 `已支付` 订单金额之和。未支付、已取消不计金额。
- **是否下单** = 订单数 > 0。

样例：张伟有 GEO 已支付 9.9 元、舆情平台未支付 8,600 元 → 订单数 2，订单金额 9.90。

### 4.5 计分样例

张伟轨迹：


| 时间                  | 行为         | 得分  |
| ------------------- | ---------- | --- |
| 2026-03-12 10:24:18 | 完成注册       | +10 |
| 2026-03-12 10:26:02 | 登录         | +2  |
| 2026-08-05 10:18:00 | 点击 9.9 元体验 | +10 |
| 2026-08-05 10:20:36 | 进入订单页      | +15 |
| 2026-08-10 10:02:18 | 登录         | +2  |
| 2026-08-22 14:18:00 | 点击 9.9 元体验 | +10 |
| 2026-08-28 14:02:11 | 绑定主体       | +20 |
| 2026-08-28 14:08:40 | 提交开票       | +10 |


行为分 = 10+2+10+15+2+10+20+10 = **79** → **热**。

关键事件次数 = 点击 9.9×2 + 进入订单页 + 绑定主体 + 提交开票 = 5。最近关键行为 = 提交开票。

## 5. 验收清单

- [ ] 列表不展示联系人ID、客户主体ID；联系人姓名在手机号前
- [ ] 字段顺序：姓名 → 手机号 → 昵称 → 邮箱 → 单位 → 账号 → 来源 → 渠道 / 标签 → 产品与状态 → 时间 → openid / unionid
- [ ] 详情为全屏覆盖；上方主表字段，下方行为汇总 / 轨迹 / 规则
- [ ] 行为汇总、行为轨迹不分产品，无产品切换；表底不再出现「按产线分开计算」
- [ ] 行为轨迹可按天筛选时间范围；筛选只改轨迹表，行为分 / 等级仍按全部轨迹
- [ ] 行为汇总无开票状态；订单数含全部产品；订单金额只含已支付
- [ ] 来源仅 模力通App / GEO小程序；来源标签、关键行为、行为轨迹枚举与本文一致
- [ ] 打标签值为 S / A / B / C，不是来源标签
- [ ] 转表单必填单位、姓名、手机号、产品；成功后列表「表单ID」回显 2xxxxx
- [ ] 行为分 = 全部轨迹之和，冷 / 温 / 热与 4.3 一致
- [ ] 邮箱、姓名未绑主体时可空
- [ ] 操作列为详情、打标签、转表单
