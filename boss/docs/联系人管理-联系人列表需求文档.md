# 蜜度 BOSS · 联系人管理 / 联系人列表 需求文档

> 版本：V1.8  
> 日期：2026-09-20  
> 适用对象：产品讲解、交互确认、前后端开发  
> 所属模块：联系人管理 / 联系人列表  
> 字段来源：《联系人表单0910》  
> 原型入口：菜单「联系人管理」 / `?page=contact` / `contact.html`
>
> **结构约定**：主表字段出现在联系人**列表**；详情为**全屏覆盖页**，先展示主表全部字段，下方再展示子表行为。

---

## 1. 背景与目标

运营在 BOSS 中查看官网/小程序注册的联系人主档，并点进详情查看该联系人按产线记录的行为轨迹与意向温度（冷/温/热）。

当前样例产线：**蜜度GEO小程序评估套餐**、**舆情平台**。行为分按产线分开计算。

| 模块 | 菜单位置 | 展示内容 | 操作 |
| --- | --- | --- | --- |
| 联系人列表 | 联系人管理 | 主表字段 | 详情、打标签、转表单 |
| 详情弹窗 | 列表点详情 | 全屏：主表全部字段 + 行为汇总/轨迹 | 关闭 |

联系人 ≠ 客户。客户管理菜单保留。

### 2.1 身份状态

`已注册未下单`、`已下单未开票`、`已绑定主体`、`已开票`。

### 2.2 数据状态

`正常`、`无效`、`已合并`。

### 2.3 行为等级（GEO 口径）

| 等级 | 分数 | 运营动作 |
| --- | --- | --- |
| 冷 | 10–20 | 刚注册或零星登录；销售暂不跟进，池内自动培育 |
| 温 | 21–45 | 浏览、点击 9.9 体验或填表；进线索池，SDR 初步触达 |
| 热 | 46 以上 | 进订单页、绑定主体、提交开票；销售立刻跟进 |

GEO 计分（按产线）：注册+授权手机号+同意协议 +10；登录一次 +2；点击「9.9元体验」+10；进入订单页 +15；绑定主体 +20；提交开票 +10。

### 2.4 筛选

按主表常用字段筛选，条件之间为且：

联系人ID、官网账号ID、手机号、客户主体名称、联系人姓名、昵称、邮箱（包含匹配）；来源详情、一级/三级渠道（**包含**匹配）、二级渠道（固定字典，**包含**匹配）、来源标签、是否已转表单、意向产品线、已购产品线、身份状态、行为等级、数据状态（精确）；入库时间（日期闭区间）。

按钮：查询、重置、批量导入（原型占位）。分页每页 10 条。

## 3. 详情内容

点「详情」打开**全屏覆盖**弹窗（盖住整页，含侧栏）。

标题：`联系人详情 【{联系人ID}】` + 当前产线行为等级。身份状态、数据状态只在基本信息中展示。

上半部分 **基本信息**：展示主表字段（四列表格式），含联系人ID、官网账号ID、手机号、客户主体ID/名称、邮箱、姓名、昵称、openid、unionid、来源详情、一级/二级/三级渠道、来源标签、意向/已购产品线、身份状态、行为分、行为等级、数据状态、表单ID、入库/更新时间、最新操作人。一级渠道、三级渠道只在详情展示。行为分、行为等级随所选产线变化。不含备注、来源渠道、联系人来源、创建人。

下半部分 **行为**：右侧产品线下拉（选项来自意向/已购/轨迹中的产线，默认蜜度GEO）。切换后行为汇总、轨迹、合计得分、等级与规则匹配均按当前产线重算。

宽屏时行为汇总与行为轨迹左右分栏，规则表在下方通栏。

### 3.1 行为汇总

以表格展示，列：序号、字段、内容。

| 字段名 | 中文名 | 必填 | 说明 |
| --- | --- | --- | --- |
| first_login_at | 首次登录时间 | 否 | datetime |
| login_count | 登录次数 | 否 | 默认 0 |
| last_active_at | 最近活跃时间 | 否 | datetime |
| last_behavior | 最近关键行为 | 否 | 如：点击 9.9 体验 |
| key_event_count | 关键事件次数 | 是 | 默认 0，点击体验/发票等累计 |
| has_order | 是否下单 | 否 | 0 / 1，详情展示是/否 |
| order_count | 订单数 | 否 | |
| order_amount | 订单金额 | 否 | |
| invoice_status | 开票状态 | 否 | 未申请 / 申请中 / 已开票 |

### 3.2 行为轨迹

`behavior_track`（json）。每条必须带产品线，行为分按产线分开算。

详情表格列：序号、时间、产品线、行为、得分。表底增加「合计得分」，为当前轨迹各行得分之和。

无数据：「暂无该产品线的行为轨迹」。

轨迹表下方为**行为等级规则表**（不再用段落说明），列：等级、分数区间、规则、匹配。当前产线命中的等级标「当前」并高亮。

| 等级 | 分数区间 | 规则 |
| --- | --- | --- |
| 冷 | 10–20分 | 刚完成注册或零星登录，销售暂不跟进 |
| 温 | 21–45分 | 有浏览、点击 9.9 元体验或填写表单，可由 SDR 初步触达 |
| 热 | 46分以上 | 进入订单页、绑定主体、提交开票，销售需立刻跟进 |

表底说明：行为分按产线分开计算，当前为{所选产品线简称}。底部：关闭。

### 3.3 列表操作

- **详情**：打开全屏详情。
- **打标签**：勾选来源标签后保存，更新来源标签与最新操作人。
- **转表单**：未转时弹出表单，**单位、联系人姓名必填**（可预填已有值）。确认后生成 2 开头 6 位表单 ID，写回联系人的单位/姓名，并在列表「表单ID」列回显。已转则按钮禁用。

## 4. 验收清单

- [ ] 列表列对应主表字段，不含子表登录/下单/开票等字段
- [ ] 详情为全屏覆盖；上方主表全部字段，下方行为汇总/轨迹/规则
- [ ] 身份状态、行为等级（冷/温/热）、数据状态展示正确
- [ ] 已删除来源渠道、备注、创建人；创建人改为最新操作人
- [ ] 列表不展示联系人来源、一级渠道、三级渠道；二级渠道在列表展示
- [ ] 详情展示一级/二级/三级渠道
- [ ] 来源标签可筛选、可打标签
- [ ] 转表单必须填写单位和联系人姓名；成功后列表「表单ID」回显 2xxxxx，未转为「否」
- [ ] 操作列为详情、打标签、转表单
- [ ] 邮箱、姓名未绑主体时可空
- [ ] 行为轨迹每行带产品线；GEO 样例分数与冷温热档位一致

---

## 5. 非目标

- 不在列表切换启用/停用、不编辑、不改密、不删除
- 批量导入仅占位
- 不在本页维护渠道/产品线字典本身
- 客户管理仍为独立菜单
- 转表单仅生成表单号，不跳转线索列表
