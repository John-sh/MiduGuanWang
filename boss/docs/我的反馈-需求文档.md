# 蜜度 BOSS · 我的反馈

> 版本：V1.0  
> 日期：2026-11-19  
> 适用对象：产品确认、前端 / 后端开发  
> 依据原型：`ticket.html` 中的「我的反馈」页与「反馈详情」弹窗  
> 关联文档：`docs/统一客户反馈工单系统-需求与流程.md`

本页给已登录账号看自己提交的反馈和处理进度。页面不展示转单、内部部门、处理人和内部备注。

---

## 1. 使用范围

只查询**当前登录账号作为提交人**的反馈。按提交时间倒序，提交时间取受理时间，没有则取创建时间。一次展示全部，不分页，不做筛选。

没有数据时，列表区显示「暂无反馈」。

页头右侧有「问题反馈」。点击后进入客户填写反馈，并清空表单，作为一次新的客户提交，不带入当前工单内容。

与客户填写反馈之间可以来回切换。当前页为「我的反馈」。

---

## 2. 列表

宽度大于 768px 用表格。宽度不超过 768px 用卡片。两套展示同一批数据。

### 2.1 电脑表格

| 列 | 取值 | 空值 |
| --- | --- | --- |
| 反馈ID | 意见反馈 ID | — |
| 业务类型 | 售前工单 / 售后工单 | — |
| 问题子类 | 工单上的问题子类 | — |
| 反馈阶段 | 工单反馈阶段，见 2.3 | — |
| 产品项目 | 优先取该客户账号对应的产品；没有则用工单上的产品项目 | — |
| 问题详情 | 客户提交的问题详情原文 | — |
| 操作 | 详情；去评价。进度到「已完成」时可点击，其他状态置灰 | |

超长的反馈 ID、问题子类、产品项目、问题详情单行省略，悬停可看全文。

### 2.2 手机卡片

每条一张卡片：

| 位置 | 内容 |
| --- | --- |
| 标题 | 工单标题；没有标题时用问题详情；都没有时显示「反馈」 |
| 状态 | 对客进度，见 2.4。处理中为蓝色，待评价为橙色，已完结为绿色 |
| 辅助信息 | `反馈ID · 产品项目 · 提交时间`。产品项目取工单上的产品项目。提交时间到分钟，格式 `YYYY-MM-DD HH:mm` |
| 摘要 | 问题详情 |
| 操作 | 「查看进度」；「去评价」。进度到「已完成」时可点击，其他状态置灰 |

### 2.3 反馈阶段（表格列）

与意见反馈工单的反馈阶段一致，纯文本：

| 工单阶段 | 列表显示 |
| --- | --- |
| 待处理 | 待处理 |
| 处理中、挂起、已转销售、已纳入需求池 | 处理中 |
| 待确认完结 | 待确认完结 |
| 已完结 | 已完结 |
| 超时完结 | 超时完结 |
| 退回 / 驳回 | 退回 |

### 2.4 对客进度（手机状态、详情里的列表状态文案）

| 条件（按顺序判断） | 对客进度 |
| --- | --- |
| 评价状态为已评价，或工单阶段为已评价 | 已评价 |
| 评价状态为已推送 | 待评价 |
| 工单阶段为已完结、超时完结，或工单状态为已完结 | 已完结 |
| 其余 | 处理中 |

手机卡片上，对客进度为「已评价」时，文字显示「已完结」，颜色仍为绿色。

### 2.5 去评价

电脑表格和手机卡片都显示「去评价」。

进度步骤到达「已完成」时按钮可点击。已完成对应工单阶段为已完结、超时完结、已评价。其他状态按钮置灰，点击无效果。

已有评分时，再次点击提示「该工单已提交满意度评价」，不打开调查页。

## 3. 反馈详情

点击「详情」或「查看进度」，打开标题为「反馈详情」的弹窗。

### 3.1 头部

| 项 | 规则 |
| --- | --- |
| 标题 | 工单标题；没有则用问题详情；都没有则显示「反馈」 |
| 副标题 | `反馈ID {意见反馈ID} · 产品项目 {产品项目}`。产品项目取工单上的产品项目 |
| 状态 | 已评价显示「已评价」；待评价、已完结，或工单已关闭，显示「已有结论」；其余显示「处理中」 |

工单已关闭：阶段或状态为已完结、已评价、超时完结。

### 3.2 进度步骤

四步，从左到右：已受理、处理中、待确认、已完成。

当前步高亮，之前的步骤记为完成。

| 工单情况 | 当前步 |
| --- | --- |
| 已完结、超时完结、已评价 | 已完成 |
| 待确认完结 | 待确认 |
| 处理中、挂起、已转销售、已纳入需求池，或已有内部流转 | 处理中 |
| 其余（含待处理） | 已受理 |

### 3.3 最新结果

| 顺序 | 条件 | 展示 |
| --- | --- | --- |
| 1 | 有处理结果或完结说明 | 展示该段文字，去掉末尾句号 |
| 2 | 还没到「已完成」 | 正在处理，完成后会同步结果 |
| 3 | 已到「已完成」，但没有结果文案 | 问题已处理完成 |

更新时间取完结时间，没有则取状态变更时间，再没有则取提交时间，到分钟。文案为「更新时间 YYYY-MM-DD HH:mm」。

### 3.4 评价区

| 对客进度 | 展示 |
| --- | --- |
| 已完成，且未评分 | 「服务已完结，邀请您评价」。说明：两个维度各 1–5 星，文字选填，约 30 秒。按钮「去评价」可点击 |
| 未到已完成 | 按钮「去评价」置灰 |
| 已有评分 | 「已收到您的评价」。说明：感谢反馈。如还有问题，可以继续联系客服 |

底部始终有「去评价」和头部状态。只有进度为「已完成」时「去评价」可点击，其他状态置灰。状态按钮不可点击。

另有按钮「还有问题？联系客服」。点击后关闭详情，进入客户填写反馈，并清空表单。按钮下说明：工作时间 9:00–18:00 · 通常数分钟内响应。

弹窗底部固定文案：本页仅展示对客可见进度，不含转单/内部部门。

---

## 4. 去评价

进度为「已完成」时，列表和详情里的「去评价」进入该工单的满意度调查，并带上该工单 id。其他状态按钮置灰。

调查页本身的免登录、工单简要和回写规则，见《统一意见反馈工单系统》8.1。从本页进入时账号已经登录，仍回写到这张工单，不另建评价。

提交成功后：

- 两项评分和文字反馈写回该工单。
- 评价状态改为已评价。
- 回到本页后，「去评价」仍在。再次点击提示已提交。详情评价区为「已收到您的评价」，头部状态为「已评价」。

---

## 5. 验收

1. 只出现当前登录账号提交的反馈，按提交时间从新到旧排列。
2. 无数据时显示「暂无反馈」。
3. 电脑为 2.1 的七列表格，手机为 2.2 的卡片。
4. 每条都有「去评价」。只有进度为「已完成」时可点击，其他状态置灰。
5. 详情步骤、最新结果、评价邀请与第 3 节一致。
6. 详情和列表都不出现处理人、内部状态、部门、转单和内部备注。
7. 「问题反馈」和「还有问题？联系客服」都进入一份清空后的客户填写反馈。
8. 「去评价」打开对应工单的满意度调查，提交后的评分能在本页反映为已评价。
